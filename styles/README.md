# Webflow CSS

These files hold the saved CSS used in Webflow. Their names describe the part
they style. Webflow keeps ordinary layout, editable content and component styles;
these files cover the extra CSS.

They are not included in the JavaScript bundle and are not loaded automatically
from GitHub. To update a Webflow Code Embed, compare its current code with the
matching file, then put that CSS between `<style>` and `</style>` in the existing
code field. Check its affected placements before publishing. A file being saved
here does not prove the current staging page uses it.
