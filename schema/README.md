# Structured-data source

`site.json` contains the shared Organization and WebSite graph. `pages/` contains
page JSON-LD referring to those shared identities. These are source payloads,
not a script that changes page settings or a record of what is currently live.

Before an approved delivery, reconcile each page’s URL, visible content and
metadata with its intended host and current page plan. Keep entity references
consistent. Include only supported facts; confirm Trust claims, legal versions
and Compare scope in their existing decision owners. Source presence does not
approve a page for public inclusion.

JSON-LD is data; retain its page/item context. Any executable CSS or JavaScript
used around it follows global code delivery. Setting changes and raw operation
records belong outside this public source folder. Saved settings, publication
and the emitted source on the approved host need separate checks.
